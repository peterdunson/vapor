=== 1. the DP prior on delta_j^2 ===

  BASE MEASURE.  The atom shared by the series in a cluster is drawn from a
  gamma whose shape is as + (Teff * n_j)/2 and whose RATE is bs + v_j/2, so
  the base measure itself (n_j = 0) is Gamma(shape = as, rate = bs):
      src/vapor.cpp:672  double atom = randg(distr_param(as + 0.5*(Teff*nj_val(j)),
      src/vapor.cpp:673  1./(bs + 0.5*v_atoms(j))));

      src/vapor.cpp:435  double phi  = R::rbeta(alpha+1., (double)n);
      src/vapor.cpp:436  double gam1 = a + k, gam2 = b - log(phi);
      src/vapor.cpp:437  double pi   = (gam1-1.) / (n*gam2);
      src/vapor.cpp:438  return (log(randu()) < log(pi)-log1p(pi))
